# API Developer Experience

Welcome to the SmartLink Nigeria API documentation. 

Our APIs enable secure, rapid identity verification and payment automation for Nigerian businesses and developers.

## Getting Started
To get started with our APIs, you will need an API key. Please contact our support team to request access.

## Base URL
All API requests are made relative to our production base URL:
`https://api.smartlink.ng` (for production)
